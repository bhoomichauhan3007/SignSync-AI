SIGN PICTURES
=============
alphabet/  a.jpg ... z.jpg   real reference photos of each letter (from the team's dataset)
words/     <word>.svg        picture cards for the 40 words (names listed in src/signs.js)

To replace a word card with a real photo, add a file with the same name ending in .jpg or .png
(for example words/hello.jpg). The app always uses a photo when one exists.
Names are lowercase. Use photos you took yourself, or pictures whose licence allows educational use.
